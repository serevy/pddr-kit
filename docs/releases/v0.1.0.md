# PDDR Kit v0.1.0

`v0.1.0`は、PDDR Kitの最初の安定版です。重要なProject / Product / Process判断を、その背景、実装、検証と結び付けて残すためのMarkdown-firstな仕様、テンプレート、AI向けSkill、導入・更新・検証CLIを提供します。

## 含まれるもの

- PDDR v0.1の仕様とMarkdownテンプレート
- 判断状態と提供状態を分離したライフサイクル
- `unknown`と`needs-confirmation`を使った不確実性の保持
- PDDRをPolicyとして無条件に適用しないConsumption Contract
- `pddr-recorder` Skill
- 非破壊な`init`、記録の`validate`、差分確認付きの`upgrade`
- 管理ファイルのハッシュを保持する導入先マニフェスト
- PDDR Kit自身の7件のPDDRとGitHub Actionsによる継続検証
- 記録作成・更新11ケースと、安全解釈4ケースの評価資料・生出力・判定結果
- Issueを実験・作業、PDDRを重要な判断に使い分ける導入指針

## 検証済みの範囲

- PDDR Kit自身でのdogfoodingとCI
- 既存プロジェクト（Audio Guardian）への初回導入、安全な更新、PDDR CI、既存のWindows CI
- 性質の異なる二つ目の既存プロジェクトへの導入、記録作成、PDDR CI
- 新規プロジェクト[`semantic-decision-lab`](https://github.com/serevy/semantic-decision-lab)への初期導入、記録作成、PDDR CI
- GPT-5.6 Sol / mediumによる記録作成・更新: 11/11
- GPT-5.6 Luna / mediumによる記録作成・更新: 10/11
- GPT-5.6 Sol / mediumとLuna / mediumによるConsumption Contract: それぞれ4/4

公開Evidenceは[`PDDR-0003`](../records/PDDR-0003-first-external-adoption-findings.md)、モデル評価の条件と結果は[`skill-evaluation.md`](../skill-evaluation.md)を参照してください。

## 既知の制約

- Lunaの記録作成・更新評価では、状態判定は正しかったものの、1ケースで既知の選択肢が下書きから欠落しました。完全性は人または上位モデルによる確認が必要です。
- マニフェスト導入前の既存環境で`--bootstrap-manifest`を使う場合は、現在の管理対象ファイルが正しい基準であることを人が先に確認する必要があります。
- 検証器は形式、状態、参照の整合性を確認します。文章や判断の妥当性、Evidenceが主張を裏付けるかは人がレビューします。
- Jevなどの有償・外部サービスは任意拡張であり、本リリースの依存関係には含まれません。

## v0.1.0-rc.1からの主な更新

- 二つ目の異なる既存プロジェクトと新規プロジェクトで導入経路を追加検証
- 既存導入先で`upgrade --dry-run`から更新、導入先CIまでの安全な更新を検証
- IssueとPDDRの責務境界を導入ガイドへ追加
- 実利用Evidenceとstable判断をREADME、Roadmap、PDDRへ反映

## 導入前の注意

PDDRはPolicyではなく、判断の文脈とEvidenceです。現在のユーザー指示、プロジェクト方針、組織Policyを優先し、記録の新しさ・反復・表現の強さだけから権限を推測しないでください。導入・更新方法は[`docs/adoption.md`](../adoption.md)を参照してください。
